For teachers

Answer key

Worksheet 1
A opening tag, B attribute name, C attribute value, D content, E closing tag. Mistakes: the first <p> should close with </p>; <h1> closes with </h2>, it should be </h1>; the <img> needs alt="…". HTML = what things are, CSS = how they look, JavaScript = what they do.
Worksheet 2
html, head, title, body, h1. Tags: <strong>, <em>, <mark>, <abbr>. Tree: html at the top, with head (title) and body (h1, p) below it.
Worksheet 3
ol, ul, dl, ol. <a href="types.html">Learn the types</a>. <img src="squirtle.png" alt="Squirtle, a little blue turtle Pokémon">. Alt words let people who can’t see the picture know what it shows.
Worksheet 4
text, number, date, checkbox, email. The for must be "trainer".
Worksheet 5
.fire: Charmander and Growlithe. #partner: Pikachu. li: all four. .water: Squirtle. h1 is the selector, color the property, red the value. Winners: .mouse, #pika, .mouse (tie, so the last one wins).
Worksheet 6
Inside to outside: content, padding, border, margin. Widths: 130, 264, 110. #ffcb05 hex, rgb(…) rgb, gold name, hsl(…) hsl.
Worksheet 7
flex, grid, flex, grid. flex-start: all on the left; center: all in the middle; space-between: one at each end and one in the middle. .grid { display: grid; grid-template-columns: repeat(4, 1fr); }
Worksheet 8
Answers will vary. Look for a clear plan, a real animation idea and an honest checklist.
