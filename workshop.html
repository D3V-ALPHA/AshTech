JS

Why do some labs say JS?

The labs without a badge are pure HTML and CSS, just like the rest of AshTech. The labs marked JS use a third language, JavaScript, because they need to read what you type or move a slider and then change the page straight away.

Think of it like this: HTML is the skeleton, CSS is the clothes and paint, and JavaScript is the muscles and brain. Once you love HTML and CSS, JavaScript is the next adventure on the route!

Teachers: every lab has a For teachers panel with a goal, questions to ask and a quick activity. The Present button fills the whole screen, which is great for a classroom projector. There are full lesson plans on the Teachers page.

Anatomy of a tag

HTML is made of tags. Hover over (or tap) each coloured part to learn its name.

<a href="pokedex.html"> Open the Pokédex </a>

  • Opening tag. Says what kind of thing this is. <a> means “a link”.
  • Attribute name. Extra information about the tag. href means “where the link goes”.
  • Attribute value. The information itself, always in quotes.
  • Content. What people see on the page.
  • Closing tag. The same name with a /. It says “the link ends here”.
For teachers

Goal: students can name the five parts of an HTML element.

Ask the class:

  • Which part would you change to send the link to a different page?
  • What would happen if the closing tag was missing?

Quick activity: write <img src="pikachu.png" alt="Pikachu"> on the board. Students point out the tag name, each attribute and each value. Why does <img> have no closing tag?

Every element is a box

Each box has four layers: the content, then padding (space inside), then a border, then margin (space outside). Switch on 3D to pull the layers apart.

border
padding
For teachers

Goal: students can name the four layers of the box model, from the inside out.

Ask the class:

  • Which layer has a colour you can see: margin, border or padding?
  • Where does the background colour stop: at the padding or at the margin?

Flexbox playground

Flexbox lines things up in a row (or a column). Pick different settings and watch the Poké Balls move. The code updates too!

For teachers

Goal: students can line items up in a row with display: flex, justify-content and align-items.

Ask the class:

  • Which setting spreads the Poké Balls out to the edges?
  • What is the difference between space-between and space-evenly?

Quick activity: students predict where the balls will go BEFORE clicking each option, then check. Keep score!

Grid playground

Grid makes rows and columns at the same time. The Pokédex uses it for its cards. How many columns do you want?

Columns 
.grid {
  display: grid;
  grid-template-columns: repeat(, 1fr);
  gap: 1rem;
}
For teachers

Goal: students can make a grid of columns with grid-template-columns and repeat().

Ask the class:

  • With 8 Pokémon and 3 columns, how many rows do we get? Why is the last row not full?
  • When would you use grid instead of flexbox?

Quick activity: open the Pokédex page and make the window narrower. Count how the columns change. That is repeat(auto-fill, minmax(210px, 1fr)) at work.

Specificity Showdown JS

When two CSS rules both want to colour the same thing, who wins? The more specific selector! IDs beat classes, and classes beat tags. If it’s a tie, the rule written last wins.

VS

Pikachu

<p id="pika" class="electric mouse">Pikachu</p>

Try these battles

  1. p vs .mouse
  2. .electric vs .mouse (a tie! Which one is written last?)
  3. p.electric.mouse vs #pika
  4. :where(#pika) vs p (:where counts as zero!)
For teachers

Goal: students understand that specificity is counted in three columns (IDs, classes, tags) and compared left to right, like a score.

Ask the class: can ten classes ever beat one ID? (No! The ID column is checked first.)

Quick activity: write a selector on the board and have students hold up fingers for its three numbers before checking here.

Does your browser know the new tricks?

Browsers learn new CSS all the time. @supports asks “do you understand this?” and only uses the rule if the answer is yes.

  • :has() Yes! The games will work.Not yet. Try a newer browser for the games.
  • Scroll-driven animations Yes! Watch the bar at the top as you scroll.Not yet. The top bar won’t fill up.
  • Page transitions Yes! Pages open like a camera lens.Not yet. Pages just appear.
