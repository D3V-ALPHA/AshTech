For teachers

AshTech is free to use in class, with no sign-ups, no ads and no data collected. Here are eight ready-to-go lessons, printable worksheets and a picture handbook for your students.

Using AshTech in class

  • Projector ready. Every Workshop lab has a Present button that fills the screen.
  • Teacher notes built in. Open the green For teachers panel under any Workshop lab for questions to ask and a quick activity.
  • View the code. Students can press Ctrl + U on any page to read its real HTML, full of comments written for learners.
  • Internet needed. Pokémon pictures, sounds and fonts load from the web. The worksheets and handbook work offline once downloaded.
  • Private by design. Nothing students type is sent anywhere. The Trainer Card is made inside their own browser.
  • Mostly HTML and CSS. The games use no JavaScript at all, which makes them great “how did they do that?” puzzles for older students.

Lesson plans

Open a lesson to see its goals, the pages to use, a step-by-step plan and an exit question.

Lesson 1 What is a web page?

By the end, students can…

  • Explain what a browser and a server do
  • Name the three languages of the web and their jobs
  • Point out the parts of an HTML tag

Use these pages

  • Workshop: Anatomy of a tag
  • Home page (look at the source with Ctrl+U)
  • Kids’ Handbook, chapter 1, 2, 3
  • Worksheet 1

The lesson

  1. Warm up (5 min) Ask: “What happens between typing an address and seeing a page?” Draw the Handbook chapter 1 diagram on the board together.
  2. Explore (15 min) On the Workshop, hover each coloured part of the tag. Then press Ctrl+U on the Home page and hunt for five tags.
  3. Make (15 min) Worksheet 1: label a tag and spot the mistakes.
  4. Wrap up (5 min) Skeleton, clothes, muscles: which language is which?

Exit question: Write one HTML tag and label its opening and closing parts.

Lesson 2 The page skeleton and text tags

By the end, students can…

  • Write the basic structure of an HTML page
  • Use headings and paragraphs
  • Choose text tags by meaning (strong, em, mark)

Use these pages

  • Workshop: Code Lab (Blank page)
  • Workshop: Tags for words
  • Kids’ Handbook, chapter 4
  • Worksheet 2

The lesson

  1. Warm up (5 min) Show the skeleton diagram (Handbook chapter 4). What goes in the head? What goes in the body?
  2. Explore (10 min) Read the “Tags that give words meaning” table together. Why do strong and b both exist?
  3. Make (20 min) In the Code Lab’s blank page, write a short “About my favourite Pokémon” page with an h1, two paragraphs and one strong word. Then Worksheet 2.
  4. Wrap up (5 min) Share one page on the projector using Present mode.

Exit question: Put these in order: body, html, head.

Lesson 3 Lists, links and pictures

By the end, students can…

  • Choose between ol, ul and dl
  • Write a working link
  • Add a picture with helpful alt text

Use these pages

  • Pokédex (cards are a list!)
  • Regions (links to #spots on the page)
  • Kids’ Handbook, chapter 5
  • Worksheet 3

The lesson

  1. Warm up (5 min) Close your eyes while I read out a picture’s alt text. Can you guess the picture?
  2. Explore (10 min) Find a list, a link and a picture on the Pokédex page. Use F12 to check which tags they are.
  3. Make (20 min) In the Code Lab, add a list of your three favourite Pokémon, each with a picture and alt text. Then Worksheet 3.
  4. Wrap up (5 min) Why is the gym list on the Regions page an ol and not a ul?

Exit question: Write an img tag for Eevee with good alt text.

Lesson 4 Forms and inputs

By the end, students can…

  • Connect a label to an input with for and id
  • Pick the right input type for a question
  • Explain what happens when a form is sent

Use these pages

  • Trainer Academy (the big form)
  • Trainer Card (where the answers go)
  • Kids’ Handbook, chapter 6
  • Worksheet 4

The lesson

  1. Warm up (5 min) List real forms students know: logins, quizzes, orders. What do they all have?
  2. Explore (15 min) Everyone fills in the Academy form, submits it, and finds their answers in the address bar. Then download the Trainer Card!
  3. Make (15 min) Worksheet 4: design a Pokémon Centre check-in form on paper.
  4. Wrap up (5 min) Why does every input need a label? (Think about screen readers.)

Exit question: Which input type would you use for a birthday? For a favourite colour?

Lesson 5 CSS rules and selectors

By the end, students can…

  • Name the parts of a CSS rule
  • Use tag, class and id selectors
  • Explain which rule wins when two disagree

Use these pages

  • Workshop: Selector Detective
  • Workshop: Specificity Showdown
  • Kids’ Handbook, chapter 7, 8, 13
  • Worksheet 5

The lesson

  1. Warm up (5 min) Show a CSS rule and label selector, property and value together (Handbook chapter 7).
  2. Explore (20 min) Pairs solve the eight Selector Detective missions. Then try three Specificity Showdown battles.
  3. Make (10 min) Worksheet 5: Selector Detective on paper.
  4. Wrap up (5 min) Can ten classes beat one id? Vote, then check in the Showdown.

Exit question: Write a selector that picks every element with class="water".

Lesson 6 The box model and colours

By the end, students can…

  • Name the four layers of the box model
  • Calculate the total width of a box
  • Write one colour in hex, rgb and hsl

Use these pages

  • Workshop: Every element is a box (3D)
  • Workshop: Measure the box
  • Workshop: Colour Mixer
  • Kids’ Handbook, chapter 9, 11
  • Worksheet 6

The lesson

  1. Warm up (5 min) Switch on the 3D box model. Name the layers from the inside out.
  2. Explore (15 min) Use Measure the box to answer: “make the whole box 200px wide with a 10px border.” Then play Match the type! in the Colour Mixer.
  3. Make (15 min) Worksheet 6: box maths and colour codes.
  4. Wrap up (5 min) What does box-sizing: border-box change?

Exit question: Content 100, padding 10, border 5, no margin. How wide is the box?

Lesson 7 Layout with flexbox and grid

By the end, students can…

  • Line items up in a row with flexbox
  • Build rows and columns with grid
  • Choose flex or grid for a design

Use these pages

  • Workshop: Flexbox playground
  • Workshop: Grid playground
  • Pokédex (a real grid)
  • Kids’ Handbook, chapter 10
  • Worksheet 7

The lesson

  1. Warm up (5 min) Predict where the Poké Balls go for each justify-content value, then click to check.
  2. Explore (15 min) Change the grid columns from 1 to 4. Then make the Pokédex window narrower and watch its grid adapt.
  3. Make (15 min) In the Code Lab, open “Flexbox team” and add a fifth Pokémon. Then Worksheet 7.
  4. Wrap up (5 min) Flex or grid: a photo gallery? A menu bar? A chessboard?

Exit question: Draw where three boxes go with justify-content: space-between.

Lesson 8 Animation and the final project

By the end, students can…

  • Write a simple @keyframes animation
  • Use transform to move, turn and resize
  • Plan and build a small page of their own

Use these pages

  • Workshop: Move Studio
  • Evolution lab
  • Workshop: Code Lab (Make it move)
  • Kids’ Handbook, chapter 12, 15, 16
  • Worksheet 8

The lesson

  1. Warm up (5 min) Watch an evolution. Which CSS properties do you think are changing?
  2. Explore (10 min) Move Studio: compare linear, ease-in-out and steps(5) on the same animation.
  3. Make (20 min) Worksheet 8: plan a “My Pokémon” page, then start building it in the Code Lab.
  4. Wrap up (5 min) Gallery walk. Hand out Handbook certificates to finishers!

Exit question: Name the three parts of the animation shorthand you used.
