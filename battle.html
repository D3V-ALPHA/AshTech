How it works

  • Every move button is a <label> for one of 16 hidden radio buttons.
  • Each checked radio sets a CSS variable, like --d1: 60, for the damage done that turn.
  • The HP bars are worked out with calc(), clamp() and max(), then animated with a transition.
  • Even the HP number is CSS: a counter is set to the HP value and shown with content.
