The secret: CSS can remember things

Web pages usually need JavaScript to remember what you clicked. Our games use a clever trick instead.

Tap the switch!

<input type="checkbox" id="light">
<label for="light">Switch</label>
#light:checked ~ .bulb {
  background: yellow;
}

A <label> with a for attribute clicks its checkbox for you, even when the checkbox is hidden. Then the :checked selector lets CSS change anything that comes after it. That’s how every game on this page remembers your moves.
