How it works

  • Each Pokémon is a <label> for a hidden checkbox. Tapping it checks the box.
  • They pop up with @keyframes. Each one has its own speed and animation-delay, set with CSS variables.
  • Everything waits with animation-play-state: paused until you press Start.
  • The timer is one long animation. When it ends, the “Time’s up” panel slides over the field.
